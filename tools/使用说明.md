# MarkdownNote

个人 Markdown 笔记与知识管理工具。

## 安装与打开

需要 Windows 64 位系统和已安装的 Microsoft Edge WebView2 Runtime。安装包不会自动安装 WebView2。

- 安装版：运行 setup.exe，选择可写目录，安装后双击目录内的 MarkdownNote.exe。
- 便携版：完整解压 portable.zip，再双击 MarkdownNote.exe；请保留同目录的隐藏标记文件。

不需要安装 Node.js、Rust 或配置 API Key。

## 使用

支持 Markdown 编辑、分屏预览、分类、标签、正文检索与高亮、双向链接、文本导入和单篇 Markdown 导出。
笔记右键可重命名、管理标签、移动、导出或删除；删除前会要求确认。
可拖动笔记到分类、拖动标签到笔记、拖动另一篇笔记到正文插入双向链接。
网页链接在预览中点击后通过默认浏览器打开。

Ctrl+S 保存，F8 切换专注模式，F11 切换全屏，Esc 退出相应模式。浅色与深色主题可在界面切换。

## 数据与备份

笔记库、Markdown 镜像和 WebView 数据位于程序同目录的“运行数据”，日志位于“日志”。
需要备份时先保存并关闭整个程序，再复制完整“运行数据”目录。
当前采用单机本地库，不提供云同步、多人协作、插件市场或 PDF 导出。

重复运行同一笔记库只保留一个程序实例。已有安装会阻止覆盖；重新安装前先保存、退出并运行“卸载程序.exe”。卸载保留运行数据和日志。
安装位置由安装包旁的记录与目标目录标记识别，不使用 Windows 全局注册表；安装包移到另一目录并选择全新位置可形成独立安装。
